# 腾讯云ssl证书配置教程：免费证书申请、域名验证到部署上线，不碰服务器配置也能开通 HTTPS

腾讯云 SSL 证书配置有两条路线。第一条是常规流程：申请证书、完成域名验证、下载证书装到服务器上。第二条叫一键 HTTPS，证书由腾讯云的 WAF 接管，你只需要加一条 CNAME 解析，服务器上的配置文件一行都不用改。

选哪条，取决于三件事：域名有没有在腾讯云备案、域名是否已经接入腾讯云 CDN 或 CLB、以及你手里有没有服务器的管理权限。下面这份腾讯云 SSL 证书配置教程就按实际操作顺序，把两条路线拆开讲。

> **选购速览**：只有一个域名、自己管服务器，免费证书就够用，验证通过后 24 小时内签发，成本为零。子域名多，看 DV 通配符；企业官网需要展示企业资质、要绑定公网 IP，看 OV；银行、金融类机构看 EV。不想碰服务器配置，直接考虑一键 HTTPS，前提是域名已备案、没接 CDN 或 CLB。👉 查看腾讯云 SSL 证书的当前套餐与价格

## 先选路线：传统部署和一键 HTTPS 差在哪

差别在证书装在哪里、出问题时你该找谁。传统部署把证书文件交到你手里，装进服务器或云负载均衡，HTTPS 握手在你的服务器上完成；一键 HTTPS 把这一步交给了腾讯云 WAF，流量先到 WAF，完成 HTTPS 后再回源到你的服务器。

| 对比项 | 传统部署 | 一键 HTTPS（安全防护版） |
| --- | --- | --- |
| 证书装在哪 | 你自己的服务器或云资源 | 腾讯云 WAF |
| 主要操作 | 下载证书、改服务器配置 | 控制台添加域名、配 CNAME |
| 前置条件 | 证书已签发 | 证书已签发 + 购买一键 HTTPS + ICP 备案 |
| 明显限制 | 需要自己维护配置 | 域名已接入腾讯云 CDN 或 CLB 时无法使用 |

一键 HTTPS 有基础版和安全防护版两个版本，本文说的是安全防护版，两者的部署方式一样，选购时留意区分。

## 第一步：申请证书，免费的和付费的差在哪

免费证书能满足大部分个人站和小型官网的需求，但它只认单个域名，泛域名和 IP 地址都不支持。付费套餐按域名覆盖范围和审核强度分级，签发的等待时间也不同。

免费证书的申请路径如下：

1. 注册腾讯云账号并完成实名认证，没实名认证没法继续。
2. 登录 SSL 证书控制台，在“我的证书”页面点“申请免费证书”。
3. 填写证书绑定域名，只能填单个域名，比如 `tencent.com` 或 `ssl.tencent.com`。
4. 选择域名验证方式。
5. 提交申请，完成域名验证。
6. 等待签发，CA 机构在 24 小时内完成。

免费证书有三个容易忽略的限制：只支持二级域名及其子域名，不支持 IP 和泛域名；同一主域存在申请数量上限，亚洲诚信体系内最多 20 张，包含你在其他平台申请的记录，撞上上限只能换域名或转付费套餐；到期不能直接延长，需要重新申请并重新部署。

选法可以很简单：单域名站点用免费证书；子域名超过一两个，DV 通配符比逐个申请更省事；政府、企业、电商类网站要展示企业身份或绑定公网 IP，从 OV 起步；银行、金融类机构再看 EV。👉 到选购页对比免费与付费证书的差别

## 第二步：域名验证，三种方式怎么选

签发前必须证明域名归你所有。腾讯云提供三种验证方式，域名已经托管在 DNSPod 的，优先用自动 DNS 验证，系统会帮你添加解析记录，最省事。

- **自动 DNS 验证**：仅当域名托管在 DNSPod 控制台时可用，系统自动添加验证记录。
- **手动 DNS 验证**：到你的 DNS 服务商处手动添加一条解析记录，生效后回控制台点验证。
- **文件验证**：在网站根目录放置指定的验证文件，适合没有 DNS 管理权限、但有服务器文件权限的情况。

提交后盯一下验证状态。控制台会显示验证中、验证超时或验证失败，“验证超时”指系统检查超过 30 秒仍未成功。遇到失败先别急着重提，检查解析记录是否已经生效，或者验证文件能不能通过公网直接访问。生效时间和 TTL 有关，TTL 越长，等的时间越久。

## 第三步（路线 A）：下载证书，部署到服务器

证书签发后，在 SSL 证书控制台就能下载。腾讯云按服务器系统（Linux 或 Windows）和服务器类型提供对应的安装文档，找到和你环境匹配的那一份照着做即可。不同服务器软件的配置写法不同，以官方安装文档为准。

这里有一个容易踩的坑，写在官方文档的注意框里：申请证书时如果填了私钥密码，之后就没法把这张证书一键部署到腾讯云负载均衡、CDN 等云服务。如果你的证书最终要挂到这些云资源上，申请时私钥密码一栏留空；已经填了的，重新申请一张不设密码的证书。

服务器本身就在腾讯云的话，可以不走手动安装。证书支持一键部署到负载均衡、CDN 等 11 种腾讯云资源，省去下载和配置的步骤。

## 第三步（路线 B）：一键 HTTPS，加一条 CNAME 就完事

一键 HTTPS 适合不想登录服务器改配置、或者源站不方便直接暴露的场景。前置条件有三个：证书已经在腾讯云签发、已经购买一键 HTTPS（安全防护版）、域名完成 ICP 备案。备案是硬门槛，没备案的域名接不进来。

操作分两步。

**添加一键 HTTPS 域名。** 在控制台的一键 HTTPS 页面点“一键添加”，填写这些内容：

- **域名**：要接入的域名，必须已在腾讯云备案。
- **证书**：选择已签发的证书，证书绑定的域名必须和这里填的域名对应。填 `cloud.tencent.com` 就选绑定 `cloud.tencent.com` 的证书，选错证书会接入失败。
- **源站地址**：选 IP 或域名。IP 填源站公网 IP，域名填源站真实域名。
- **强制 HTTPS**：开启后，浏览器端的 HTTP 请求会收到 302 重定向到 HTTPS 地址。
- **回源协议**：开启后腾讯云使用 HTTP 协议访问源站。
- **回源端口**：默认支持 80 和 8080，按源站实际情况选。

**配置 CNAME 记录。** 添加域名后，控制台会提供一个 CNAME 域名，去 DNS 服务商加一条记录：主机记录填子域名（比如 `cs.dnspod.com` 填 `cs`），记录类型选 CNAME，线路类型选默认，选其他线路会导致部分用户无法解析；记录值粘贴控制台给出的 CNAME 域名，TTL 默认 600 秒。域名托管在 DNSPod 的可以直接一键添加。解析生效后接入就完成了，生效时间一般和 TTL 一致。

这套方案的限制得提前说清楚：默认开通的是 WAF 小微版，额度是 1 个二级域名、8 个子域名、50 QPS，www 子域名也占一个子域名名额；如果域名已经接入腾讯云 CDN 或 CLB，一键 HTTPS 用不了，只能走传统部署。👉 了解一键 HTTPS（安全防护版）的当前方案

## 证书快到期：续期不等于延长旧证书

续期这里有个容易误解的点：续期操作实际是在控制台重新申请一张新证书，旧证书的有效期不会因此延长。新证书签发后，需要重新安装部署到服务器或云资源，旧证书在有效期内照常可用。

免费证书在过期前 30 天会开启快速续期通道，在 SSL 证书控制台的“我的证书”页面点“快速续期”，按提示完成域名验证即可，不需要付费。验证方式和首次申请一样，DNS 验证或文件验证二选一。

另外，自 2020 年 9 月 1 日起，全球 CA 机构不再签发超过 2 年期的 SSL 证书，别指望一次买多年省事，到期前记得处理。付费证书支持自动续费，免费证书只能手动续。

## 常见问题

**免费证书能用在多个子域名上吗？**
不能。一张免费证书对应一个域名。多个子域名要么逐个申请，要么选 DV 通配符套餐，覆盖主域名下所有下一级子域名。

**一键 HTTPS 必须备案吗？**
必须。ICP 备案通过的域名才能添加一键 HTTPS，未备案的域名接入会失败。

**申请时填了私钥密码，还能部署到负载均衡或 CDN 吗？**
不能。需要部署到腾讯云负载均衡、CDN 等云服务时不要填写私钥密码。已经填了的，重新申请一张不设密码的证书最省事。

**域名验证一直失败怎么排查？**
先看解析记录是否已生效，文件验证则确认验证文件能通过公网直接访问。显示“验证超时”表示系统检查超过 30 秒未成功，可以稍后重试；显示“验证失败”多半是记录填错了。

**证书多久能签发下来？**
免费证书和 DV 证书最快。免费证书在验证通过后 24 小时内签发，DV 套餐官方标注 1 天；OV 需要 1–3 个工作日，EV 需要 3–5 个工作日，时间主要花在审核企业资料上。

## 最后：按你的情况对号入座

- 只有一台服务器、一个域名：免费证书 + 传统部署，零成本。
- 子域名一堆：DV 通配符，一张证书覆盖主域名下一级子域名。
- 不想碰服务器配置，或源站想藏在 WAF 后面：一键 HTTPS，先确认域名已备案、没接 CDN 或 CLB。
- 企业官网要展示资质、绑定公网 IP：OV；银行、金融类机构：EV。

下单前确认两件事：证书绑定的域名和你要配置的域名完全一致；要部署到腾讯云负载均衡或 CDN 的话，申请时别填私钥密码。👉 按你的站点情况查看对应证书价格
